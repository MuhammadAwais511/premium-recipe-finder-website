# 🍳 What's In My Kitchen? — Recipe Finder

A modern, responsive recipe discovery website that helps users explore delicious meals, discover new recipes, and find inspiration for their next cooking experience. Browse recipes, search for meals, and explore dishes from around the world.

## ✨ Features

- 🔍 **Recipe Search** — Search for recipes by name.
- 🍽️ **Recipe Discovery** — Explore a variety of delicious meals.
- 📖 **Recipe Details** — View recipe information, ingredients, and cooking instructions.
- 🌎 **Explore International Cuisine** — Discover meals from different countries and cultures.
- 📱 **Responsive Design** — Works on desktop, tablet, and mobile devices.
- ⚡ **Fast & Modern UI** — Clean, modern, and user-friendly interface.
- 🥗 **Food Categories** — Discover recipes by different categories.
- 🖼️ **Food Images** — Beautiful food imagery for an engaging experience.

## 🛠️ Tech Stack

- **Next.js** — React framework for building modern web applications.
- **React.js** — UI library for building interactive interfaces.
- **Tailwind CSS** — Utility-first CSS framework for styling.
- **JavaScript** — Application logic and functionality.
- **TheMealDB API** — Recipe data, meal information, ingredients, and images.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/recipe-finder.git
```

### 2. Navigate to the Project Directory

```bash
cd recipe-finder
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Development Server

```bash
npm run dev
```

### 5. Open in Browser

Visit:

```text
http://localhost:3000
```

## 🔗 API

This project uses **TheMealDB API** to retrieve recipe information.

- API: https://www.themealdb.com/api.php

The API provides meal information, recipe images, ingredients, cooking instructions, categories, and more.
