# Recipe Finder

A responsive recipe discovery app built with Next.js, React, and TypeScript. Find meals by name or ingredient, browse categories, and save recipes and shopping items.

## Features

- Search recipes and discover meals
- Browse categories and ingredients
- View recipe details and cooking instructions
- Save favorites and recently viewed recipes
- Manage a shopping list
- Switch between light and dark themes

Recipe data is provided by [TheMealDB](https://www.themealdb.com/api.php).

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

- `npm run dev` - Start the development server
- `npm run build` - Create a production build
- `npm run start` - Start the production server
- `npm run lint` - Run ESLint
